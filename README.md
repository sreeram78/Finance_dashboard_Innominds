# Nymi Inc — CFO Financial Dashboard

A static, McKinsey-styled web dashboard for the monthly Statement of
Financial Operations. A small Python script converts the raw `.xlsb`
MIS workbook into a JSON file; a single static `index.html` reads that
JSON and renders the KPIs, charts, and monthly P&L table with Chart.js.
No backend, no build step — it's plain HTML/CSS/JS and can be hosted
anywhere, including GitHub Pages.

```
nymi-cfo-dashboard/
├── index.html                  ← the dashboard (never needs raw financial data hardcoded into it)
├── data/
│   └── financials.json         ← generated by the script below; index.html fetches this at load
├── scripts/
│   └── extract_data.py         ← reads the .xlsb workbook, writes data/financials.json
├── requirements.txt
├── .gitignore                  ← keeps the raw .xlsb workbook out of git
└── .github/workflows/deploy.yml← optional auto-deploy to GitHub Pages
```

## How it works

1. Finance provisions a new monthly `.xlsb` MIS workbook.
2. You run `scripts/extract_data.py` against it — it reads the
   `"Detailed SOP"` sheet and writes `data/financials.json`.
3. You commit the refreshed `data/financials.json` (the workbook
   itself is git-ignored — it's usually too sensitive/large to store
   in source control).
4. `index.html` is unchanged from month to month. It fetches
   `data/financials.json` at page load and recomputes every KPI card,
   chart, and table row from it.

The only thing that does **not** auto-update is the free-text
commentary paragraph under "Executive summary" — that's written
analysis, not a derived number, so it's left as editable HTML. Update
it by hand, or ask an AI assistant to redraft it once you show it the
new `data/financials.json`.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Refresh the data

```bash
python scripts/extract_data.py path/to/Statement_Of_Financial_MIS.xlsb
```

This writes `data/financials.json`. If you omit the path, the script
looks for a single `.xlsb` file sitting in the project root.

If the workbook's sheet layout changes (rows inserted/removed, sheet
renamed), update the row/column map constants at the top of
`scripts/extract_data.py` — `ROW_MAP`, `COL_FY_CURRENT`,
`COL_FY_PRIOR`, `COL_MONTHS_START`, `N_MONTHS_ACTUAL`.

## View it locally

Because `index.html` fetches `data/financials.json` with `fetch()`,
opening the file directly (`file://...`) will fail in most browsers
due to CORS. Serve the folder over HTTP instead:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish to GitHub

```bash
git init
git add .
git commit -m "Initial CFO dashboard"
git branch -M main
git remote add origin https://github.com/<your-org>/<your-repo>.git
git push -u origin main
```

### Option A — GitHub Pages (recommended, zero server cost)

1. In the repo: **Settings → Pages → Source → GitHub Actions**.
2. The included workflow (`.github/workflows/deploy.yml`) will deploy
   automatically on every push to `main`.
3. Your dashboard will be live at
   `https://<your-org>.github.io/<your-repo>/`.

Each month: run `extract_data.py` locally, commit the new
`data/financials.json`, push — the site updates automatically within
a minute or two.

### Option B — any static host

`index.html` + `data/` is a fully static site. It also works unmodified
on Netlify, Vercel, S3+CloudFront, or an internal web server — just
upload the repo contents.

## Customizing

- **Colors/type/layout** — CSS variables are defined at the top of
  `index.html` (`:root { --ink: ...; --accent: ...; }`).
- **Charts** — each chart is a plain `new Chart(...)` call inside
  `buildCharts(D)` in `index.html`'s `<script>` block; add or remove
  chart blocks there.
- **New P&L line items** — add a row to `ROW_MAP` in
  `extract_data.py`, plumb it into the `out` dict, then reference it
  from `index.html`.

## Data notes

- Figures are extracted from the `"Detailed SOP"` sheet of the source
  workbook.
- Months with no data loaded yet in the workbook (e.g. the remainder
  of the fiscal year) are excluded from YTD totals and simply won't
  appear until the workbook is updated and the script re-run.
- All figures are in USD as recorded in the source workbook.
